# Stevens Slides — Dark

Read and follow the complete [Stevens Slides workflow](../stevens-slides/SKILL.md).
Select `dark` from its template manifest and keep the Dark Gray canvas,
white/light-gray text, white identifier, and gold/orange/blue data accents. Red
may appear only as a large branding plane; never use red text on Dark Gray.
