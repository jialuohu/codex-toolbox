# Focused craft principles

Taste comes from observing whether an interface responds as users expect.
Prioritize immediate feedback, a visible active state, purposeful animation,
and consistent spacing, type, depth, and motion tokens. Entering UI should use
responsive easing and a plausible origin; system responses should feel quicker
than deliberate user actions. Make gestures interruptible and reduce movement
when users request reduced motion.

For code reviews, state the observed evidence, a concrete replacement, and why
it improves interaction. Do not mistake an aesthetic preference for a required
change.
