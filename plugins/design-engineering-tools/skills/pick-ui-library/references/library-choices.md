# Curated library choices

| Need | Prefer |
| --- | --- |
| Accessible unstyled primitives | Base UI |
| Command menu | cmdk |
| Toasts | Sonner |
| OTP input | input-otp |
| General springs or layout animation | Motion |
| Animated numbers | NumberFlow |
| General dashboard charts | Recharts |
| Drag and drop | dnd kit |
| Large-list virtualization | Virtuoso |
| Shared state | zustand |
| Conditional classes | clsx |
| Typed Tailwind variants | cva |
| Theme switching | next-themes |

Treat the table as a starting point; verify project compatibility and current
official documentation before recommending or installing anything.
