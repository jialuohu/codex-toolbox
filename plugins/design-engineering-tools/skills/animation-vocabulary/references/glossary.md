# Motion glossary

- **Fade in/out**: change opacity to appear or disappear.
- **Slide in**: enter from an off-screen direction.
- **Scale in**: grow from a smaller size while appearing.
- **Pop in**: a scale-in with slight overshoot.
- **Reveal**: uncover content with a clip-path or mask.
- **Stagger**: start related animations with small offsets.
- **Tween / interpolation**: generate intermediate values between keyframes.
- **Morph**: smoothly transform one shape into another.
- **Crossfade**: overlap two states while their opacity swaps.
- **Shared-element transition**: move and transform the same conceptual object
  between locations.
- **Layout animation**: animate a layout change to preserve spatial continuity.
- **Rubber-banding**: resistance and snap-back beyond a scroll/drag boundary.
- **Origin-aware animation**: expand from the triggering element, not center.
- **Spring**: physics-like, interruptible motion responding to velocity.
