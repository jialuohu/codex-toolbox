# Provenance

This plugin adapts eight skills from https://github.com/emilkowalski/skills at
commit `85e8e2363b713506e1d5b6e07a0eb2da66be1bc3`, under its MIT license.

It is an unofficial, non-affiliated adaptation. Local changes add Codex
`agents/openai.yaml` policy, progressive disclosure, safe read-only defaults,
Plan Mode boundaries, and toolbox workflow routing.

The eight adopted source documents are preserved in each skill's
`references/upstream.md`, removing only the leading YAML frontmatter to avoid
duplicate skill metadata. [The import receipt](upstream.json) records each
immutable source path and both source and imported SHA-256 checksums. Existing
supporting references are unchanged by this upstream refresh. Additional
upstream skills are not included.
