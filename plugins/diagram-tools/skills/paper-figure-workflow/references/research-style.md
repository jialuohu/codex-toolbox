# Research figure style for new AI and systems paper figures

Use this guide for **new** research figures, or when a user asks to restyle an existing one. Read [shared research composition](../../research-figure-style.md) for source references, diagram composition, and per-setting precedence. This guide owns publication data, dimensions, typography, and regeneration. Do not modify existing figures merely because the default changed.

## Plots and encodings

Start with a 3.3-inch single-column or 6.9-inch double-column width, 8-point body text, and no text smaller than 7 points **at final placement size**. Size a plot before labels and legends. Reserve canvas space for legends and annotations instead of using a tight export crop. For Matplotlib, `bbox_inches=None` preserves the requested canvas; `bbox_inches='tight'` computes a content-dependent bounding box ([Matplotlib `savefig`](https://matplotlib.org/stable/api/_as_gen/matplotlib.pyplot.savefig.html)). Inspect the exported SVG and PDF at the actual paper size for clipping, label overlap, arrow direction, and grayscale readability.

Declare method order and style mappings once for a figure set. The included `method_styles.json` fixes color, marker, line style, and hatch by method name. Reordering input records or omitting a method must leave the other appearances unchanged. Require a new distinct encoding, or use a separate panel, when adding a method. Use an explicit unit on every quantitative series and on its axis. Reject incompatible units instead of converting without a stated rule.

Grouped bars take explicit estimates. If they show uncertainty, include bounds, the statistic represented by each bar, interval type, calculation method, sample count, and a confidence level for confidence intervals. Each lower/upper pair must contain its estimate. An empirical cumulative distribution function (ECDF) uses raw observations and plots `F(x) = count(samples <= x) / n`. Repeated observations cause one step of the appropriate size. Percentiles in the example use the observed nearest-rank rule, with no quantile interpolation. A missing line value is a gap; do not silently drop, interpolate, or fill it. Stacked bars and areas require every component at every point of a common grid, in compatible units. Values are additive and are not normalized. The area example explicitly requests linear drawing **between** the supplied time points; the bars example performs no interpolation.

The examples are fixed, clearly labeled synthetic data. Their numeric values support testing and illustration only. Replace them with measured or cited values, and record any aggregation or normalization in the project source and caption.

## Fonts, sources, and regeneration

The portable baseline uses DejaVu Sans, embedded TrueType fonts in PDF (`pdf.fonttype=42`), and editable SVG text (`svg.fonttype='none'`). SVG text depends on recipient fonts; a recipient without DejaVu Sans may see substituted glyphs or different line breaks ([Matplotlib font guide](https://matplotlib.org/stable/users/explain/text/fonts.html)). Record the actual selected font and any substitution, verify PDF embedding with `pdffonts`, and inspect unusual glyphs in both outputs. The starter's export check measures SVG/PDF widths within 0.01 inch and checks the smallest editable text after any planned placement scaling.

Copy plotting scripts, shared validation helpers, style file, mapping, explicit input data, pinned requirements, diagram sources, the recorded owner, and the Makefile into the paper project. OmniGraffle projects also copy the guarded runtime and template assets, including six accepted native `.graffle` starters and their palette/acceptance manifest. Resolve assets relative to those copied scripts. Run `make plots` for plots, `make diagrams` for the recorded owner, and `make figures` for both. Missing dependencies and failed exports must stop the command; an old file is not proof of regeneration. Draw.io retains editable `.drawio` files. OmniGraffle retains saved `.graffle` and editable equations; later export reads the native file rather than recreating it from the initial seed. Archify retains its existing presets, delivery gate, and visual review; this guide does not change its schema or permissions.
