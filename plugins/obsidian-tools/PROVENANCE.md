[kepano/obsidian-skills](https://github.com/kepano/obsidian-skills/tree/3ccff5338ea700537839b21900aa5358a0402c98),

source paths and SHA-256 checksums.

original import did not record its upstream revision; its Toolbox snapshot
identity remains in each receipt's `historical_import` field. This verification
does not claim that snapshot was originally imported from the current commit.

disclosure. Upstream `SKILL.md` files remain named `UPSTREAM.md` to avoid duplicate
skill registration. The additional upstream Knap skill is not adopted.
