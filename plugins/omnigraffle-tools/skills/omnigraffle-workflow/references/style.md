# Overridable research defaults

Adapted from the supplied workflow; explicit choices and project conventions take precedence.

- Start with Helvetica/Helvetica Bold at 16 pt, including natural-size math. Use an installed CJK-capable font for Chinese text; visually verify glyph coverage. Reflow before shrinking labels.
- Use repeated node templates with consistent dimensions, padding and alignment. Flat rounded cards and restrained fills are a starting point, not a requirement.
- Keep connectors behind opaque components and labels above them. Route according to actual dependencies; do not invent edges, measurements or execution claims.
- Keep legends near the reading start and differentiate stage numbers from component-type badges. Preserve semantic colors and explain dashed or faded states.
- Align math and prose by visible baselines; inspect arrowheads, line joins and clipping at publication size. Preserve exact notation from the paper or source.

English, Chinese and mixed instructions have equal status. Preserve an existing figure's language unless translation is requested. Example: “统一 node margin 和 icon alignment，图内 labels 保留英文” changes geometry while retaining English labels.
