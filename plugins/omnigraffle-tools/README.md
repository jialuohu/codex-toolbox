# OmniGraffle Tools

Use `$omnigraffle-workflow` for explicit OmniGraffle requests and existing `.graffle` diagrams. The plugin provides local commands and workflow guidance; it has no MCP server or persistent daemon.

Start with [the skill](skills/omnigraffle-workflow/SKILL.md) and [command contract](skills/omnigraffle-workflow/references/commands.md). Run the bundled CLI's `doctor` before native work. Native drawing uses OmniGraffle scripting; genuine equation editing uses official LaTeXiT GUI automation on an unlocked Mac.

Default toolbox setup installs plugin files only. OmniGraffle, official LaTeXiT, TeX dependencies and application permissions are separate explicit setup actions. The production CLI passed licensed-Mac native drawing, export and real LinkBack acceptance, including editing after both apps restarted. See [acceptance evidence and supported limits](ACCEPTANCE.md); portable tests alone do not establish native readiness.

See [provenance](PROVENANCE.md) for the shared archive and separate upstream licensing. Publication and installed-profile rollout require the explicitly invoked shipping workflow.
